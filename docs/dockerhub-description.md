# 随手传 · Pocket Relay

在设备之间，随手发，随时取。

轻量自部署消息收件箱，用浏览器同步文字、图片、动图、视频和任意文件。适合 NAS、本机电脑和小型 VPS。支持 linux/amd64、linux/arm64，公共镜像可匿名拉取。

## 最简 Docker Compose

将以下内容保存为 docker-compose.yml，或直接粘贴到 NAS 的 Compose 页面，无需 .env、初始密码或 setup-token：

```yaml
services:
  pocket-relay:
    image: stylle/pocket-relay:latest # 公共镜像，无需登录；可固定为 v0.3.1
    container_name: pocket-relay     # 可省略，也可改名
    restart: always                 # 建议保留；恢复备份需要重启
    ports:
      - "28182:8080"                # 左侧访问端口可改，右侧不改
    volumes:
      - relay-data:/data            # 必须保留，持久化账户、密钥、配置和本地文件
volumes:
  relay-data:                       # 上面命名卷的必需声明
```

```bash
docker compose -f docker-compose.yml up -d
```

打开 `http://服务器IP:28182`，在可信内网绑定标准 TOTP 验证器。**第一个完成绑定的账户为永久管理员**，首次初始化前不要直接暴露公网。二维码也可用密钥手动添加；请备份验证器。

默认使用 Docker 命名卷。如需指定文件夹，将挂载改为 `/srv/pocket-relay/data:/data`，删除末尾顶层 volumes 声明。v0.2.0 起，启动阶段自动初始化专用 data 权限，随后降权以 UID/GID `10001:10001` 运行服务；无需手动 chown 或设置 PUID/PGID、user。升级时移除临时添加的 user 配置。

必须使用本项目专用目录，初始化会将其目录/文件权限设为 700/600 并调整所有者，不要挂载共享资料库或系统目录。为防误操作，拒绝符号链接、硬链接、嵌套挂载及特殊文件。只读挂载、NAS ACL、SELinux、NFS root-squash 等宿主机限制仍需宿主机授权；不需要 777、特权模式或 Docker socket。显式指定非 root user 时跳过初始化，需自行保证可写。

## 登录与账户

- 登录时可勾选「记住登录状态（7 天）」，默认不勾选。勾选后固定 7 天内重新打开网页、浏览器和正常重启容器无需验证，不受空闲超时影响，访问不会延长期限。
- 长期凭据使用 HttpOnly、SameSite=Strict Cookie，服务端仅存哈希，不使用 localStorage；公网请使用 HTTPS。主动退出撤销该浏览器的记住状态及关联会话，临时账户到期仍失效。请勿在公用设备上勾选。
- 未勾选时，仅同一标签页刷新保留登录，新打开页面需验证，遵循后台空闲超时规则；默认无操作 15 分钟退出，后台可设分钟、天或关闭。普通会话不跨服务重启。
- 每账户最多 32 个记住状态、全站 2048 个，超出时撤销最早创建的；运行中每账户最多 64 个会话、全站 10000 个。网站导出的备份不包含记住状态；直接备份 data 需保护登录状态。
- 公开注册默认关闭；后台开启后，新账户默认有效 1 小时，可配置时长或延长已有账户。到期停止访问，不自动删除永久消息。
- 同一账户共享收件箱，不同账户数据隔离。一个验证码只能使用一次，多设备登录请等待下一组；设备时钟需同步。

## 消息与文件

登录默认显示「本次消息」，历史已折叠，点击「全部信息」查看；同一标签页刷新不重置本次登录时间。搜索只在「全部信息」显示，本次消息和文件页不显示搜索栏。文本搜索覆盖本账户全部历史，可选今天、最近 7/30 天或自定义时间，每页 100 条继续加载；不搜索附件内文。后台可关闭默认加载图片，改为点击后加载。

发送文字可选「隐私发送（遮挡正文）」；完整正文不随列表返回，点击「显示正文」才读取，刷新恢复遮挡。**这只是防旁观的显示功能，不是密码加密、端到端加密，也不加密附件和数据库中的消息文字。**

支持文字、表情、图片、动图、视频和任意文件，多选、拖放或粘贴图片；Ctrl / ⌘ + Enter 发送。文字可复制，文件可下载。复制图片需要 HTTPS 或 localhost 以及浏览器支持；GIF 复制静态首帧，下载保留动图。

默认永久保留，发送时可选有效期或自定义分钟。到期即停止访问，后台约一分钟清理附件；远程删除失败会重试，删除不等于物理安全擦除。默认单文件 256 MB、每账户 5 GB，后台可修改。后台每 4 秒同步消息，页面可见时进行。

设备名称在网页设置，浏览器无法读取系统用户名；来源 IP 默认脱敏。反代环境显示代理的脱敏 IP，不信任客户端提供的 X-Forwarded-For。

## Telegram 机器人

默认关闭，在「管理后台 → Telegram 机器人」配置，无需新增部署参数或公网回调。使用长轮询，只需能够通过 HTTPS 访问 api.telegram.org。一个专用机器人绑定一个站内账户和一个 Telegram 私聊，不接收群聊、频道、其他私聊或机器人消息。

1. 私聊官方 [@BotFather](https://t.me/BotFather)，发送 /newbot 创建专用机器人，取得 Token。
2. 将 Token 填进网站后台。先在 Telegram 私聊自己的机器人发送 /start，再点击「检测连接 / 识别私聊 ID」，核对选择 ID，也可手动填写正整数 Chat ID。
3. 选择归属账户，分别开启「接收 TG 消息到网站」和「网站新消息发送到 TG」，打开总开关并保存，不用重启容器。修改已启用的聊天绑定时先关闭同步；账户过期会停止同步。

接收文字、照片、视频、音频、文件和贴纸附件，可预览格式由浏览器决定；存入归属账户当前的本地/WebDAV/SMB 存储，默认永久保留。接收会去重，只处理开启后的信息；只发送网站新消息，不补发历史或循环回发 TG 来源消息。

官方云端接口目前接收附件最多 20 MB、发送附件最多 50 MB；同时受站点上限和配额约束。超限会显示文字提示，不影响网站上传更大的文件。长文字分段，附件作为原始文件发送。状态显示最近收发时间、待发/失败数与错误；自动重试，发送连续失败 10 次后暂停该条，可手动重试。一个机器人仅一个接收实例；Webhook/其他轮询冲突会提示，不会删除别的应用的 Webhook。

**开启发送会把消息交给 Telegram 保存。**隐私遮挡消息默认不转发，可显式开启转发完整正文和附件；网站删除、到期或遮挡不会删除 TG 副本。机器人聊天不是端到端加密。Token 加密保存在 data，网页不回传已存 Token，留空表示保留；不要公开 Token。

修改配置或关闭同步会取消在途请求并清空旧发送队列，无法撤回 Telegram 已收到的内容。重启保留队列和分段进度；网络响应丢失时仍可能重复投递。备份包含机器人配置与队列，恢复前停止旧实例。必要时可自行配置标准 HTTPS_PROXY / HTTP_PROXY，默认不需要任何环境变量。

## 存储

后台可选择本地、WebDAV 或 SMB；远程存储通过读写测试后再保存并设为默认。切换仅影响新文件，旧附件仍使用原配置。

WebDAV 填完整服务地址及可选子目录。SMB 填主机、账户及「共享名/子目录」，使用 TCP 445，建议只在可信内网或 VPN 中使用；镜像内置 rclone，仅执行 SMB 操作时启动。

元数据和密钥保存在 /data，TOTP 与远程密码使用 AES-256-GCM 加密。**密钥和数据库同卷保存，拿到完整 data 仍可能解密；不是端到端加密，本地附件不做内容加密。**请保护宿主机与备份，并通过 HTTPS 远程访问。

## 备份、恢复与更新

后台可下载密码加密 .prb 备份，包含数据库、密钥、所有用户数据和本地附件。WebDAV / SMB 仅备份连接配置和索引，远程文件本体需另行备份。备份密码至少 12 字符，丢失无法恢复。

恢复先验证备份，重启时替换数据；旧数据保留在 /data/previous-*。保留 restart: always，恢复上限 20 GB，需要足够临时磁盘空间。服务恢复后重新登录。大量本地数据也可先停容器，再完整备份 data 卷。

更新前备份，保留原项目名与原数据卷，执行：

```bash
docker compose -f docker-compose.yml pull
docker compose -f docker-compose.yml up -d
docker compose -f docker-compose.yml logs --tail=100
```

不要执行 `docker compose down -v`，它会删除命名卷。固定版本部署时将 image 改为所需的已发布版本标签。

当前未接入个人微信或企业微信消息回调。容器内 /data 必须持久化；日志、数据库、备份和完整部署凭据不要上传公共仓库。
