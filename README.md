# 随手传 · Pocket Relay

在设备之间，随手发，随时取。

轻量自部署消息收件箱，用浏览器同步文字、图片、动图、视频和文件。适合 NAS、本机电脑和小型 VPS。

## 能做什么

- 同一账户、多设备同步，消息互相隔离；支持拖放、多选与粘贴图片。
- 复制文字和图片、下载文件，消息默认永久保留，也可设置有效期。
- 标准 TOTP 验证器登录；刷新保留登录、可配置空闲超时、主动退出；公开注册默认关闭。
- 本次消息与历史折叠；全部记录文字/时间搜索；网址、邮箱、手机号可点击；原文复制不变。
- 点隐私消息展开，刷新重新隐藏；已发消息可设为/取消隐私（非内容加密）。图片使用小缩略图，点击查看原图；隐私图片点击前不加载。
- 手机紧凑输入框；后台消息字号大/中/小，保存后所有设备沿用；视频仍按需加载，不自动播放。
- Telegram 机器人双向同步，后台独立开启接收/发送，绑定私聊和归属账户；默认关闭。
- 本地、WebDAV、SMB 存储；密码加密的整站备份与恢复。

## 最简部署

支持 `linux/amd64` / `linux/arm64`。[Docker Hub 公共镜像](https://hub.docker.com/r/stylle/pocket-relay)，可直接拉取，无需登录。

将以下内容保存为 `docker-compose.yml`，或直接粘贴到 NAS 的 Compose 管理页面：

```yaml
# 飞牛 / 通用 NAS：可直接上传此文件或复制到 Compose 项目中。
# Docker Hub 公共镜像，可直接拉取，无需登录。
services:
  pocket-relay:
    image: stylle/pocket-relay:latest # 必填；公共镜像，无需仓库凭据
    container_name: pocket-relay             # 可省略，也可改名
    restart: always                         # 建议保留，恢复备份时需要重启
    ports:
      - "28182:8080"                        # 左侧为 NAS 访问端口，可改；右侧不改
    volumes:
      - relay-data:/data                    # 必须保留；数据由 Docker 命名卷保存

volumes:
  relay-data:                               # 必填，与上面的卷名一致

# 不需要 environment 或 .env；第一次打开网页绑定验证器。
# 请保留数据卷；删除卷会删除账户、密钥、配置和本地附件。
```

```bash
docker compose -f docker-compose.yml up -d
```

打开 `http://服务器IP:28182`，在可信内网绑定验证器。**第一个完成绑定的账户获得永久管理员权限。**无需环境变量、`.env` 或 setup-token；命名卷由 Docker 管理权限。

## 使用边界

网址识别 HTTP/HTTPS、www，浏览器新标签页打开；邮箱通过邮件应用、手机号通过系统拨号应用处理。微信等内置浏览器会提示从菜单转到浏览器，网页无法保证强制唤起外部浏览器。只识别常见手机号/格式化号码，日期、订单号等尽量不自动转成拨号链接；不执行消息中的 HTML 或危险协议。

后台可设置「收到的 TG 消息默认设为隐私」，初始开启，仅影响以后收到的消息。隐私状态影响文本与附件预览，文件名仍显示；用户主动下载仍可获取本人附件。改变隐私会取消尚未发送的 TG 队列，不会补发取消隐私的旧消息，也无法撤回已经送达或正在发送的第三方副本。

登录时可勾选「记住登录状态（7 天）」：固定 7 天内重新打开页面、浏览器或正常重启容器无需验证，不受空闲超时影响；主动退出立即撤销，临时账户到期仍失效。默认不勾选，此时仅同一标签页刷新保留登录，遵循后台空闲超时设置。长期凭据使用 HttpOnly、SameSite Cookie，服务端只存哈希，不写入 localStorage；公网请使用 HTTPS。复制图片依赖 HTTPS 或 localhost 与浏览器支持。文件不是端到端加密；管理员整站备份包含全部账户数据，远程附件本体需另行备份。当前未接入微信机器人。


## 界面、关于与兼容升级

- 界面参考 wusaqi-gallery-go：亮色／暗色／跟随系统、纯色／炫彩配色、中英切换。顶部入口，偏好保存在当前浏览器。
- 顶部「关于」或 `/about.html` 关于页面 查看版本、版权、许可与数据安全边界。
- 本次 UI 不修改业务接口、数据库和附件布局。升级前备份完整 data，重建时继续使用同一挂载；不要删除数据卷。
- 容器服务使用 UID/GID 10001；入口仅准备专用 data 目录。NAS ACL、只读目录或特殊挂载不能自动绕过，详见迁移说明。
- [升级与迁移](docs/UI-UPGRADE.md) · [后续 Agent 复用手册](docs/AGENT-HANDBOOK.md)。手册登记发布所需的 Secret 名称与权限，绝不包含真实 Token。
